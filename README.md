### about

Я создаю быстрые и выразительные сайты — от идеи и визуального направления до запуска. Мне нравится соединять хороший интерфейс с тем, что обычно остаётся невидимым: SEO, скорость, микроразметка, интеграции и понятная структура.

**что могу собрать**

- лендинг или сайт бренда с характером, а не из конструктора;
- сервис на Next.js / React или лёгкий Astro-проект;
- онлайн-запись, Telegram-бота, CRM и другие нужные интеграции;
- техническую SEO-базу: Core Web Vitals, Schema.org и всё, что помогает сайту находиться.
